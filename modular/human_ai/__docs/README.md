# ИИ NPC: устройство модуля

Публичные DM-типы сохранены. Путь файла не является названием игрового типа.
Точка подключения — `_human_ai.dme`; subsystem и component подключаются отдельно
на прежних местах в `colonialmarines.dme`.

## Где искать логику

| Папка | Ответственность |
|---|---|
| `core` | Мозг NPC, планировщик действий, жизненный цикл, общие помощники |
| `navigation` | Построение пути, шаги, безопасные конечные точки, выход из декораций |
| `obstacles` | Выбор и выполнение способов преодоления, стоимость препятствий |
| `configuration` | Глобальные настройки, разрешения и сохранение профилей |
| `panel` | Отдельная панель Human AI: серверный обработчик, TGUI-интерфейс и документация |
| `combat` | Выбор целей, стрельба, укрытия, дистанция, обнаружение |
| `grenades` | Броски, подбор, отход, безопасность и предметные хуки гранат |
| `medicine` | Самолечение, лечение союзников, лекарства, ремонт синтетиков |
| `orders` | Приказы, следование, патрули, удержание позиции |
| `equipment` | Инвентарь, выбор оружия, перезарядка, инструменты |
| `communication` | Реплики и общение |
| `spawning` | Индивидуальные и отрядные пресеты |
| `integrations` | Компонент NPC и существующие административные инструменты |
| `tests` | Регрессии поведения и правил |

## Препятствия

Панель настроек открывается через **Game Master → HumanAI → Human AI Settings**.
Описание черновиков, трёх сложностей, глобальных настроек и трёх личных
слотов сохранения — в [`../panel/README.md`](../panel/README.md).
Настройки применяются только к живым NPC; новые получают действующий глобальный
профиль. Мёртвые исключены, включая повторную проверку после подтверждения.

`human_ai_select_obstacle_action()` выбирает физически доступное и разрешённое
действие. `human_ai_obstacle()` использует этот выбор при оценке маршрута;
`human_ai_act()` повторяет выбор непосредственно перед взаимодействием.
Старого универсального клика оружием по любому объекту больше нет.

- `obstacle_dispatch.dm`: общий контракт и выполнение разрушения.
- `door_obstacles.dm`: обычное открытие, лом, шлюзы, гермозатворы, минеральные двери.
- `structure_obstacles.dm`: перелезание, баррикады, платформы и защита техники.
- `hazard_obstacles.dm`: огонь, реки, космос, смоляные стены.
- `mob_obstacles.dm`: встречные люди и ксеноморфы; это не изменение ИИ ксеноморфов.

Действия по умолчанию разрешены, но разрешение не даёт инструмент, доступ или
способность разрушить объект. Неизвестные конструкции и техника не считаются
разрушаемыми только потому, что они плотные. Запертые/заваренные обычные шлюзы
не получают фиктивный конечный штраф, если доступного способа преодоления нет.
Взлом проводов, снятие сварки и обход подтверждений пожарных дверей не реализованы.

## Глобальные разрешения препятствий

Общий живой объект: `GLOB.human_ai_obstacle_policy`.
Метод `set_permission(action, allowed, atom_type)` принимает TRUE/FALSE/null:
null означает наследование (для общего базового значения — запрет).
`atom_type` необязателен, задаёт правило для типа и его потомков.
Неизвестные ключи отклоняются; число правил типов ограничено 256 на профиль.

Ключи:

- `open_door`: обычное открытие, включая складывание пласталевой баррикады.
- `pry_door`: штатное применение лома; специальные когти зомби учитываются отдельно.
- `climb_barricade`: перелезание через баррикады.
- `climb_structure`: перелезание через прочие разрешённые физикой конструкции.
- `destroy`: повреждение явно поддержанных препятствий подходящим оружием.

Индивидуальных профилей NPC нет. Настройки панели действуют глобально.
Для экземпляра объекта использовать
`set_human_ai_navigation_permission(action, allowed)` с теми же ключами;
метод проверяет ключ и значение перед изменением `human_ai_navigation_permissions`.

Приоритет:

1. Физические ограничения и защита разрушения — не отменяются разрешениями.
2. Запреты типа или экземпляра объекта — сильнее любых разрешений.
3. Разрешение типа/экземпляра — исключение из базового профиля.
4. Общий базовый параметр. Глобальный запрет панели не обходится разрешениями объектов.

Изменение общего профиля читается текущими и новыми NPC, без копирования при
спавне. Перед взаимодействием сохранённый маршрут проверяется заново.
Уже начатое штатное действие может завершиться безопасно по правилам игры.
Панель, пресеты и сохранение между рестартами описаны в `../panel/README.md`.

## Защита объектов и видимость NPC

`human_ai_navigation_protected` запрещает разрушение конкретного объекта.
Также учитываются `indestructible`, `unacidable`, `unslashable`.
Неизвестная принадлежность не трактуется как вражеская. Автоматическая маркировка
союзных построек требует достоверного источника фракции; текущие баррикады его
не предоставляют, поэтому используется явная защита, а не предположение.

Транзит и остановка различаются. Перелезание использует штатный `do_climb`,
который сам проверяет физику. Модуль не вводит forceMove, смену плотности или
флагов прохода. Пока идёт задержанное действие, обычный шаг не запускается.
Конечная точка выбирается на безопасном полу, при необходимости среди соседних
клеток. Если подходящего места нет, перемещение отклоняется.
Временное перекрытие спрайта при штатном перелезании возможно: это не гарантия
отсутствия всех визуальных проблем карт.

## Проверки этой версии

На 2026-10-20 производственная сборка через `tools/build/build.bat --ci dm
-DANSICOLORS -Werror` завершилась без ошибок и предупреждений.
Пропущенных и повторных подключений нет; 84 перенесённых файла без логических
правок совпали с исходными. Добавлены три теста разрешений, защиты физических
ограничений и применения общего профиля к текущим/новым NPC.
Тестовая сборка CIBUILDING заблокирована 50 существующими ошибками в
`modular/lobby_ui/code/shared/terminal_tests.dm`; тесты не были выполнены.
Проверка поведения и видимости NPC в игре ещё необходима.
