Необходимо оформить как **production-каталог проверенных build objects + rules/recipes**, а не как список красивых, но неизвестных `/obj/path`.

Главная идея:

```text id="mxtp6o"
50–70 verified object providers
→ 100–130 placement modules
→ каждый placement module ставит существующий объект или группу существующих объектов
→ каждый provider path проверяется через text2path/ispath
→ одиночный scatter запрещён для смысловой мебели
```

Текущий PR уже имеет основу: faction preset содержит реальные object paths для `table`, `chair`, `cabinet`, `bed`, `rack`, `crate`, `console`, `medical_bed`, `hydro_tray`, `toilet`, `light`, `apc`, `air_alarm`, `fire_alarm`, `light_switch` и т.д.  Также текущий `normalize_building_params()` уже резолвит shell paths и строит `fixture_providers_by_slot`, после чего валидирует capabilities preset’а.  Это надо расширить до нормального каталога.

# 3. Provider registry

## 3.1. Datum provider

```dm id="m9sday"
/datum/world_edit_building_object_provider
	var/id = ""
	var/slot = ""
	var/path_text = ""
	var/type_path = null
	var/list/styles = list()
	var/list/capabilities = list()
	var/list/categories = list()
	var/decorative_only = FALSE
	var/dense_expected = TRUE
	var/wall_mountable = FALSE
	var/source = "catalog"

	var/list/audit_errors = list()

/datum/world_edit_building_object_provider/proc/resolve()
	type_path = text2path(path_text)
	if(!ispath(type_path, /obj))
		audit_errors += "path_not_obj:[path_text]"
		return FALSE
	return TRUE

/datum/world_edit_building_object_provider/proc/provides_capability(capability_id)
	if(decorative_only)
		return FALSE
	return "[capability_id]" in capabilities
```

## 3.2. Registry

```dm id="e09gno"
/datum/world_edit_building_object_provider_registry
	var/list/providers_by_id = list()
	var/list/providers_by_style_slot = list()
	var/list/providers_by_capability = list()
	var/list/audit_errors = list()

/datum/world_edit_building_object_provider_registry/proc/register_obj(
	id,
	slot,
	path_text,
	list/styles,
	list/capabilities,
	list/categories = null,
	decorative_only = FALSE,
	dense_expected = TRUE,
	wall_mountable = FALSE
)
	var/datum/world_edit_building_object_provider/provider = new
	provider.id = "[id]"
	provider.slot = "[slot]"
	provider.path_text = "[path_text]"
	provider.styles = islist(styles) ? styles.Copy() : list()
	provider.capabilities = islist(capabilities) ? capabilities.Copy() : list()
	provider.categories = islist(categories) ? categories.Copy() : list(slot)
	provider.decorative_only = decorative_only ? TRUE : FALSE
	provider.dense_expected = dense_expected ? TRUE : FALSE
	provider.wall_mountable = wall_mountable ? TRUE : FALSE

	if(!provider.resolve())
		audit_errors += provider.audit_errors
		return null

	providers_by_id[provider.id] = provider

	for(var/style_id as anything in provider.styles)
		var/key = "[style_id]|[provider.slot]"
		if(!islist(providers_by_style_slot[key]))
			providers_by_style_slot[key] = list()
		providers_by_style_slot[key] += provider

	for(var/capability_id as anything in provider.capabilities)
		if(!islist(providers_by_capability[capability_id]))
			providers_by_capability[capability_id] = list()
		providers_by_capability[capability_id] += provider

	return provider
```

## 7.2. Candidate enumeration

```dm id="3s421s"
/datum/world_edit_generator/building_layout/proc/enumerate_module_candidates(state, room, module)
	var/list/candidates = list()

	for(var/turf/origin as anything in room.turfs)
		for(var/dir in GLOB.cardinals)
			var/datum/world_edit_building_module_candidate/C = build_module_candidate(state, room, module, origin, dir)
			validate_module_candidate(state, C)
			if(C.is_valid())
				C.score = score_module_candidate(state, C)
				candidates += C

	return candidates
```

## 7.3. Validation

```dm id="d8rxe5"
/datum/world_edit_generator/building_layout/proc/validate_module_candidate(state, C)
	for(var/turf/T as anything in C.occupied_turfs)
		if(!state.geometry.floor_lookup[T])
			C.reject_reasons += "not_floor"
		if(state.geometry.wall_lookup[T])
			C.reject_reasons += "wall"
		if(state.geometry.reserved_lookup[T])
			C.reject_reasons += "reserved_route"
		if(state.fixtures.fixture_lookup[T])
			C.reject_reasons += "occupied"
		if(state.has_anchor("door_cone", T))
			C.reject_reasons += "door_cone"

	for(var/turf/T as anything in C.clearance_turfs)
		if(state.fixtures.fixture_lookup[T])
			C.reject_reasons += "clearance_blocked"
		if(state.geometry.wall_lookup[T])
			C.reject_reasons += "clearance_wall"

	if(C.module.wall_required && !candidate_has_required_wall(state, C))
		C.reject_reasons += "no_wall"
```

	for(var/list/placement as anything in state.fixtures.object_placements)
		if("[placement["kind"]]" != "interior")
			continue

		var/slot = "[placement["slot"] || placement["requested_slot"]]"
		if(!(slot in list("table", "chair", "bed", "toilet", "medical_bed", "hydro_tray", "weapon_rack")))

	for(var/datum/world_edit_building_room/room as anything in state.geometry.solved_rooms)
		var/raw_table_chair_count = 0
		var/list/module_ids = list()

		for(var/turf/T as anything in room.turfs)

# 17. Почему вариант A

**Предпочтительность: 90%.**

Почему:

* в билде уже есть достаточно реальных объектов;
* основная проблема не в количестве paths, а в отсутствии правил размещения;
